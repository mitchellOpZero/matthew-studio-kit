# App logos

The YouTube and Instagram icons here are the platforms' official files, used as-is. The kit shows one only for a moment
when he names that app, to say which app he means, which is what both brands' guidelines allow:

- Use the official file. Don't recolour, stretch, crop, outline or animate the icon itself. The kit only fades and
  scales the whole white tile it sits on.
- Show it only beside a mention of that app. Never use it as his own logo, or in a way that suggests the platform
  sponsors or endorses him.
- Guidelines: YouTube https://www.youtube.com/howyoutubeworks/resources/brand-resources/ ,
  Instagram https://about.meta.com/brand/resources/instagram/

New logos go here as PNG files under the same rules: the brand's own file, used only when he names it.
