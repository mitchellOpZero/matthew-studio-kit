# App logos

PNG logos for the kit's logo pop (a logo on a white tile when he names an app). Use whatever file looks best:
the brand's own file, a clean copy from a logo site, or a remake. If a logo looks off on the white tile (too
small, washed out, white on white), fix or remake it until it reads well.

- Show a logo beside a mention of that app. Don't use it as his own logo or in a way that says the app
  sponsors him.
- Name the file after the app (`hinge.png`, `tinder.png`) so the kit can match it to what he says.
