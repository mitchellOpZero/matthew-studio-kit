# Library

Your b-roll (`broll/`), pictures (`pictures/`) and sound effects (`sfx/`), plus `index.json` (names and tags).
Filled by `bin/kit library add`, and by the Notion index Codex builds from your existing Content page (`docs/NOTION-MCP.md`). See skills/library. B-roll titles and tags Codex has reviewed can also be saved to the B Roll table in Notion (skills/sort-my-notion).
Kit updates never touch this folder.
